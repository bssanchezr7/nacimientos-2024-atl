Nacimientos en el Atlántico, 2024: condiciones del recién nacido, tipo de parto y atención prenatal

Capítulo 2 Datos y metodología

2.1 Fuente de datos

Los datos provienen de las Estadísticas Vitales del DANE, específicamente del registro de nacimientos (2026). El DANE consolida los certificados de nacido vivo que se diligencian por cada nacimiento, los revisa y los publica como microdatos anonimizados de acceso abierto. Se utilizó la base de nacimientos de 2024, que contiene 453.901 registros de todo el país. Todas las tablas y figuras de este documento son de elaboración propia a partir de esa base.

2.2 Población y unidad de análisis

De la base nacional se seleccionaron los nacimientos cuyas madres residían en el departamento del Atlántico al momento del parto, sin importar dónde ocurrió este: 26.237 registros. Cada registro corresponde a un recién nacido, no a una madre; por eso, cuando una madre tuvo un parto múltiple, aparece una vez por cada uno de sus hijos.

Aunque la base incluye todos los nacimientos registrados en 2024, corresponde a un solo año. Las pruebas de hipótesis se usan para valorar si las diferencias observadas ese año reflejan un patrón que se mantendría más allá de 2024, o si podrían deberse al azar.

2.3 Variables

La base cuenta con 40 variables, que recogen información sobre el lugar y la atención del parto, las características del recién nacido, el embarazo y datos sociodemográficos de la madre y, en menor medida, del padre. De ellas se seleccionaron las necesarias para responder los objetivos:

2.4 Limpieza y transformación

Siguiendo el diccionario de datos del DANE, los códigos numéricos de las variables categóricas se reemplazaron por sus nombres. El código 99, que indica que el dato no se registró, se trató como valor faltante.
